# Image generation manifest

Model: **Nano Banana Pro**. Crystal heroes at **2:3** portrait, **2k**. Question tiles at
**3:2** landscape, **1k**. Save each as PNG at the path shown. Missing files fall back to a
generated SVG gem automatically, so you can regenerate any single image any time.

Shared style for a consistent set: _"cinematic studio product photography, deep near-black
background, soft volumetric rim light, subtle particles, high detail, no text, no
watermark."_
