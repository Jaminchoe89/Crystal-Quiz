# Images

Drop AI (or photographic) images here. Anything missing falls back to a generated SVG gem,
so the app always works.

```
crystals/<crystal-id>.png   # 8 reveal-wall heroes, portrait ~2:3
   citrine, rose-quartz, amethyst, clear-quartz,
   aventurine, aquamarine, strawberry-quartz, obsidian

options/<option>.png         # 24 question tiles, landscape ~3:2
   q1-dunes q1-forest q1-sea q1-field
   q2-dawn q2-blush q2-blue q2-storm
   q3-wood q3-petals q3-stone q3-velvet
   q4-friends q4-garden q4-studio q4-water
   q5-sunbeam q5-ripple q5-candle q5-dawnglow
   q6-peony q6-bloom q6-daisy q6-iris
```

Generation prompts: `../../scripts/image-prompts.md`.
